# CEYVANA Global — Website V3

Responsive, SEO-focused CEYVANA Global website.

## Key business proof points
1,000+ shipments · 5+ countries · 100+ importers · 30+ suppliers · 8+ years in business.

## Contact form
Submits via PHP `mail()` to `hello@ceyvanaglobal.com` with BCC to `sathilad@gmail.com`. Hosting must support PHP mail; authenticated SMTP/API is recommended for production deliverability.

## Images
All images are local; no remote stock-image URLs are embedded. The hero image was generated specifically for this website. This minimizes third-party stock licensing concerns; retain your original asset/source records.

## SEO
Includes semantic HTML, title/description, keywords, canonical URL, Open Graph/Twitter metadata, Organization JSON-LD, image alt text, robots.txt and sitemap.xml. After launch, submit sitemap.xml in Google Search Console.
